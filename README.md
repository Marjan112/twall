# twall

twall is a simple TUI program for managing wallpapers

> [!NOTE]
> twall looks inside /usr/share/backgrounds and ~/.local/share/backgrounds for wallpapers

## Dependencies

- xwallpaper *on X11*
- on Wayland, only sway compositor is supported (for now)

# Quick start

```sh
cargo run --release
```
